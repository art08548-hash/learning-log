### 📚 顺带学到
- 函数默认值在**定义时**只算一次，所以不能写 `j = len(troops) - 1`；要用 `None` 再在函数里补
- 可变默认值（`def f(x=[])`）会在多次调用间共享，也要用 `None`
- 切片会复制出新列表，在切片上改不影响原列表 → 原地排序必须传 `lo`、`hi`
- `random.randint(a, b)` 两端都包含（和 `range` 不同）
- 有序输入 + 固定选末尾当 pivot → 每次只切掉一个 → O(n²)，Python 直接递归超限
- 随机 pivot 管不了「全部相等」：需要三路分区（附加挑战）
- 卡 6 三路分区：返回两个边界 `(lt, gt)`，中段一次到位；全部相等时 O(n) → [排序笔记](../notes/sorting.md)
- Python 一行交换 `a, b = b, a`：先把右边打包成元组，再从左到右拆包
