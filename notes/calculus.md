# 📒 微积分（为线性回归准备）知识笔记

> 2026-11-09 开始学习。路线：导数 → 链式法则 → 偏导 / 梯度 → 梯度下降。
> 配套练习见 [ai/math/](../ai/math/)

**为什么要学：** 线性回归（以及所有神经网络）的训练，本质上就是「在一个损失函数的山谷里找谷底」。导数告诉我们脚下的坡往哪边倾斜、有多陡，然后我们就知道该往哪走。

---

## 卡 1：导数 = 斜率

**主角：** 一个函数 `f`，和一个位置 `x`。

把 `f` 的图像想成一条山路，横轴是位置 `x`，纵轴是海拔 `f(x)`。
**`f` 在 `x` 处的导数**，就是站在 `x` 这一点时，脚下这条山路的**斜率**：往右走一小步，海拔变化多少。

| 导数的值 | 脚下的山路 |
|---|---|
| > 0 | 往右是上坡 |
| < 0 | 往右是下坡 |
| = 0 | 平的（可能是山顶，也可能是谷底） |
| 绝对值越大 | 坡越陡 |

**记号：** `f'(x)` 读作「f 撇 x」，表示 `f` 在 `x` 处的导数。另一种写法是 `df/dx`，`d` 表示「一点点变化」：`f` 的一点点变化 ÷ `x` 的一点点变化。

---

## 卡 2：数值导数（用代码近似求斜率）

**主角：** 函数 `f`、位置 `x`、一个很小的步长 `h`。

两点确定一条直线，直线的斜率 = 纵向变化 ÷ 横向变化。
在 `x` 和 `x + h` 两个很近的点上量海拔，就得到 `x` 附近的近似斜率：

```
            f(x + h) - f(x)
f'(x)  ≈  ─────────────────
                  h
```

- 分子 `f(x + h) - f(x)`：往右走 `h` 之后，海拔变了多少
- 分母 `h`：横着走了多远
- `h` 越小，这两个点越近，结果越接近真正的导数

**`h` 为什么不取 0：** 分母变成 0，没法除。
**`h` 为什么不取得特别小（比如 `1e-15`）：** 计算机里的小数有精度限制，`f(x + h)` 和 `f(x)` 几乎一样时，相减会丢掉大部分有效数字，结果反而不准。`1e-5` 左右是常用的折中。

## 卡 3：幂函数求导规则（手算导数）

**主角：** 形如 `xⁿ` 的函数（`x` 的 n 次方）。

```
(xⁿ)' = n · xⁿ⁻¹
```

即：指数 `n` 拿下来当系数，指数本身减 1。

| 函数 | 导数 |
|---|---|
| `x⁴` | `4x³` |
| `x³` | `3x²` |
| `x` | `1`（`x¹` → `1 · x⁰`） |
| 常数 `c` | `0`（平地没有坡） |

两条配套规则：
- **常数倍**：`(c · f)' = c · f'`，比如 `(5x³)' = 15x²`
- **加法**：`(f + g)' = f' + g'`，一项一项分别求导再加起来

**用途：** 手算的结果是精确值，可以用来检查卡 2 的数值导数算得对不对。

## 卡 4：`np.linspace`（等间距取点）

**主角：** 一个区间 `[start, stop]`，和要取的点数 `num`。

```python
np.linspace(start, stop, num)
```

在 `start` 到 `stop` 之间**等间距**取 `num` 个点，返回 numpy 数组，**两端都包含**。

```python
np.linspace(0, 1, 5)    # → array([0.  , 0.25, 0.5 , 0.75, 1.  ])
np.linspace(2, 3, 3)    # → array([2. , 2.5, 3. ])
```

**和 `range` / `np.arange` 的区别：**

| | 你指定的是 | 包含终点吗 |
|---|---|---|
| `range(a, b, step)` / `np.arange` | 步长 | ❌ 不包含 |
| `np.linspace(a, b, num)` | 点数 | ✅ 包含 |

**点数和间距的关系：** `num` 个点之间有 `num - 1` 个间隔，所以间距 = `(stop - start) / (num - 1)`。

## 卡 5：`np.abs`（绝对值）

**主角：** 一个数，或一个 numpy 数组。

```python
np.abs(-3)                       # → 3
np.abs(np.array([-2, 0, 1.5]))   # → array([2. , 0. , 1.5])
```

对数组是**逐个元素**取绝对值，返回同样形状的数组。

**用途：** 「离 0 有多近」看的是绝对值：`-0.1` 比 `0.5` 更接近 0，因为 `|-0.1| = 0.1 < 0.5`。

## 卡 6：把函数当参数传

**主角：** 一个接收「函数」作为参数的函数。

在 Python 里，函数也是一个对象，可以像数字一样当参数传进别的函数：

```python
def twice(g, x):          # g 是一个函数，x 是一个数
    return g(g(x))        # 对 x 连续用两次 g

def add3(x):
    return x + 3

twice(add3, 10)           # → 16，add3 后面没有括号：传的是函数本身，不是调用结果
```

**`lambda`：** 写一个临时的、只有一行的函数，不用起名字：

```python
twice(lambda x: x * 10, 2)    # → 200
# lambda x: x * 10  等价于  def 某函数(x): return x * 10
```

**和 numpy 配合：** 如果函数内部只用了 `+ - * / **` 这类运算，那么传入 numpy 数组时，这些运算会**逐个元素**进行（广播，见 [D6](derived.md#d-np-broadcast)），整个函数自动就能处理数组。

## 卡 7：`np.argmin` / `np.argmax`（最小 / 最大值的下标）

**主角：** 一个 numpy 数组 `a`。

```python
a = np.array([5, 2, 9, 1, 7])

np.min(a)       # → 1   最小的值
np.argmin(a)    # → 3   最小值在 a 里的下标（a[3] 是 1）
```

`arg` 是 argument 的缩写：「让结果最小的那个输入」。`np.argmax` 同理，找最大值的下标。

**常见用法：在一个数组里找下标，去另一个等长的数组里取值**

```python
names = np.array(["野蛮人", "弓箭手", "巨人", "哥布林", "法师"])
costs = np.array([5, 2, 9, 1, 7])

names[np.argmin(costs)]    # → "哥布林"：在 costs 里找最小的下标，去 names 里取名字
```

**易错：** `argmin` 的结果是下标（第几个），不是值。要值就得再取一次：`a[np.argmin(a)]`。

## 补充：中心差分（卡 2 的标准写法）

**主角：** 函数 `f`、位置 `x`、步长 `h`。

卡 2 的公式只往右走一步，叫**前向差分**。标准写法是左右各走 `h`，叫**中心差分**：

```
            f(x + h) - f(x - h)
f'(x)  ≈  ─────────────────────
                   2h
```

- 分子：从 `x - h` 到 `x + h` 海拔变了多少
- 分母 `2h`：这两个点之间的横向距离

| | 误差 | `x²` 在 3 处、`h = 1e-5` 的实测误差 |
|---|---|---|
| 前向差分 | 和 `h` 成正比 | 约 `1e-5` |
| 中心差分 | 和 `h²` 成正比 | 约 `4e-11` |

**用途：** 深度学习里检查自己写的反向传播对不对（gradient check），用的就是中心差分。

## 卡 8：复合函数（一个函数套着另一个函数）

**主角：** 两个函数，里层 `g` 和外层 `f`。

先把输入 `x` 交给里层 `g`，`g` 的输出再交给外层 `f`，这样串起来的整体叫**复合函数**，写作 `f(g(x))`。

例：`y = (5x - 1)³` 是两步：

| 步骤 | 谁 | 输入 | 输出 |
|---|---|---|---|
| 第 1 步（里层） | `g(x) = 5x - 1` | `x` | 记作 `u` |
| 第 2 步（外层） | `f(u) = u³` | `u` | `y` |

**为什么要引入新名字 `u`：** `(5x - 1)³` 整体不是卡 3 里的 `xⁿ`，没法直接用幂函数规则。把里层的输出起名叫 `u` 之后，外层就变成了 `u³`，这是会求导的形状。`u` 只是「里层输出」的名字，没有别的含义。

**怎么认里外层：** 算数值时**先算的是里层**，后算的是外层。

---

## 卡 9：链式法则（复合函数的斜率 = 每一层斜率相乘）

**主角：** 复合函数 `y = f(g(x))`，其中 `u = g(x)` 是里层的输出。

```
dy     dy     du
──  =  ──  ·  ──
dx     du     dx
```

- `dy/dx`：整体的斜率（`x` 变一点点，`y` 变多少）← 我们想要的
- `dy/du`：外层 `f` 的斜率（`u` 变一点点，`y` 变多少）
- `du/dx`：里层 `g` 的斜率（`x` 变一点点，`u` 变多少）

**为什么是相乘（齿轮直觉）：** 第一个齿轮转 1 圈，第二个跟着转 5 圈；第二个转 1 圈，第三个跟着转 3 圈。那第一个转 1 圈，第三个转 `5 × 3 = 15` 圈。斜率就是这种「放大倍数」，一级接一级，倍数相乘。

**为什么是相乘（式子）：** 让 `x` 变一点点 `Δx`（`Δ` 读「德尔塔」，表示「变化量」），`u` 跟着变 `Δu`，`y` 跟着变 `Δy`。

```
Δy     Δy     Δu
──  =  ──  ·  ──        # 右边的 Δu 上下约掉，就是左边
Δx     Δu     Δx
```

**例：** `y = (5x - 1)³`，求 `x = 1` 处的斜率。

1. 拆层：`u = 5x - 1`，`y = u³`
2. 里层的斜率：`du/dx = 5`
3. 外层的斜率：`dy/du = 3u²`
4. 相乘：`dy/dx = 3u² · 5`
5. 代数：`x = 1` 时 `u = 5·1 - 1 = 4`，所以 `dy/dx = 3 · 4² · 5 = 240`

**⚠️ 最容易错的地方：外层的斜率在 `u` 处取值，不是在 `x` 处。** 外层 `f` 吃进去的是 `u`，它根本不认识 `x`。上面第 5 步里，`3u²` 代的是 `u = 4`，不是 `x = 1`。

## 卡 10：多层链 + 两趟走法（前向 / 反向）

**主角：** 三层或更多层串起来的函数，例如 `x → u → v → y`。

层数再多，规则不变，每一层的斜率全部乘起来：

```
dy     dy     dv     du
──  =  ──  ·  ──  ·  ──
dx     dv     du     dx
```

每一层的斜率都在**它自己的输入**处取值：`dy/dv` 在 `v` 处，`dv/du` 在 `u` 处，`du/dx` 在 `x` 处。

所以实际计算分两趟：

| 趟 | 方向 | 做什么 | 名字 |
|---|---|---|---|
| 第 1 趟 | 从里到外 | 依次算出 `u`、`v`、`y` 的**值**，并记下来 | 前向传播（forward pass） |
| 第 2 趟 | 从外到里 | 用记下来的值算每一层的斜率，一路乘回去 | 反向传播（backward pass / backpropagation） |

**这就是神经网络训练用的反向传播。** 神经网络是很多层套起来的复合函数，反向传播就是对它用链式法则。PyTorch 的 `loss.backward()` 做的就是第 2 趟。

## 卡 11：多元函数（有好几个输入的函数）

**主角：** 一个吃两个（或更多）输入、吐出一个数的函数，例如 `f(x, y)`。

之前的函数只有一个输入，图像是一条**山路**。两个输入时，图像是一整片**山地**：`x` 是东西方向的位置，`y` 是南北方向的位置，`f(x, y)` 是那个地点的海拔。

```python
def f(x, y):
    return x ** 2 * y + 3 * y

f(2, 1)     # → 7：站在地点 (2, 1)，海拔是 7
```

**为什么需要它：** 预测公式 `w × x + b` 有两个要调的旋钮 `w` 和 `b`，损失同时取决于它们俩，所以损失是多元函数 `L(w, b)`。

---

## 卡 12：偏导数（只动一个输入时的斜率）

**主角：** 多元函数 `f(x, y)`，和其中一个被选中的输入。

站在山地上，「斜率」取决于你朝哪个方向走。**`f` 对 `x` 的偏导数**：把 `y` 钉住不动，只让 `x` 变一点点，`f` 变多少。也就是只朝东西方向走时脚下的斜率。

**记号：** `∂f/∂x`，`∂` 读作「偏」（英文 partial）。
**为什么要用新符号 `∂` 而不是 `d`：** 用来提醒「这个函数还有别的输入，它们此刻被当作常数」。算法和 `d` 完全一样。

**怎么算：把其他输入当成常数，然后按卡 3 的规则正常求导。**

例：`f(x, y) = x²y + 3y`

| 要算的 | 谁当常数 | 过程 | 结果 |
|---|---|---|---|
| `∂f/∂x` | `y` | `x²y` 里 `y` 是常数倍 → `2x · y`；`3y` 整个是常数 → `0` | `2xy` |
| `∂f/∂y` | `x` | `x²y` 里 `x²` 是常数倍 → `x²`；`3y` → `3` | `x² + 3` |

**数值版：** 和卡 2 一样量斜率，但只挪动被选中的那个输入，另一个保持原样。

---

## 卡 13：梯度（把所有偏导数装进一个向量）

**主角：** 多元函数 `f(x, y)`，和一个地点 `(x, y)`。

把每个输入的偏导数按顺序排成一个向量，就是 `f` 在这个地点的**梯度**：

```
∇f = [ ∂f/∂x ,  ∂f/∂y ]
```

**记号：** `∇` 读作「nabla」或「del」，`∇f` 读作「f 的梯度」。
**为什么要打包成向量：** 两个旋钮要同时调，把两个斜率放在一起，后面可以用一行 numpy 同时更新所有旋钮。神经网络有上亿个旋钮，梯度就是一个上亿维的向量。

例：`f(x, y) = x²y + 3y` 在地点 `(2, 1)`：`∇f = [2·2·1, 2² + 3] = [4, 7]`

**梯度的含义：**

| 性质 | 说明 |
|---|---|
| 方向 | 梯度指向**上坡最陡**的方向 |
| 反方向 | 梯度的反方向是**下坡最陡**的方向（[D19](derived.md#d-downhill) 的多维版） |
| 长度 | 梯度越长，坡越陡 |
| 谷底 | 在谷底，每个方向都是平的，梯度是零向量 `[0, 0]` |

梯度的每个分量都可以单独看：第 0 个分量是「只拧第一个旋钮」时的斜率，第 1 个分量是「只拧第二个旋钮」时的斜率。

### 补充：只有两个偏导数，怎么知道其他方向的斜率？（方向导数）

**主角：** 函数 `f(x, y)` 在某个地点的梯度 `∇f`，和一个任意的行走方向 `d`。

**问题：** 梯度只量了东西、南北两个方向的斜率，朝东北或别的方向走时斜率是多少？

**推导：** 朝任意方向走一小步，这一步可以拆成「先往东走 `Δx`，再往北走 `Δy`」。

```
海拔变化 ≈ ∂f/∂x · Δx  +  ∂f/∂y · Δy      # 东西方向的斜率 × 往东走的距离 + 南北方向的斜率 × 往北走的距离
```

右边正好是梯度 `∇f = [∂f/∂x, ∂f/∂y]` 和这一步 `[Δx, Δy]` 的**点积**。所以：

```
朝方向 d 走的斜率 = ∇f · d          # d 是长度为 1 的方向向量；这个量叫方向导数
```

**为什么两个数就够了：** 光滑的地形放大到足够近，看起来就是一块**倾斜的平板**。一块平板怎么倾斜，两个方向的斜率就完全确定了，其他所有方向的斜率都能由它们算出来。

**例：** `f(x, y) = x²y + 3y` 在地点 `(2, 1)` 的梯度是 `[4, 7]`。

| 行走方向 `d` | 斜率 `∇f · d` |
|---|---|
| 正东 `[1, 0]` | `4`（就是 `∂f/∂x`） |
| 正北 `[0, 1]` | `7`（就是 `∂f/∂y`） |
| 东北 `[0.707, 0.707]` | `4 × 0.707 + 7 × 0.707 ≈ 7.78` |
| 沿梯度方向 `[4, 7] / √65` | `√65 ≈ 8.06`（所有方向里最大） |
| 垂直于梯度 `[7, -4] / √65` | `0`（等高线方向，不上不下） |

**顺带解释了「梯度指向上坡最陡」：** 点积 `∇f · d = |∇f| · cos θ`，`θ` 是 `d` 和梯度的夹角。`d` 和梯度同向时 `cos θ = 1` 最大，反向时 `-1` 最小（下坡最陡），垂直时为 0。

**前提：** 地形在这个点是光滑的。在尖角、折痕处（比如 `|x|` 在 0 处）放大后不是平板，这个结论不成立。

## 卡 14：均方误差（MSE）与 `np.mean`

**主角：** 一批数据（很多条记录），和每条记录各自的损失。

只有一条记录时，损失是误差的平方。有很多条记录时，把每条记录的损失取**平均值**，作为整体的损失，叫**均方误差**（Mean Squared Error，缩写 MSE）：

```
MSE = (第 1 条的损失 + 第 2 条的损失 + … + 第 n 条的损失) / n
```

**为什么取平均而不是求和：** 这样损失的大小不随数据条数变化，1 万条和 100 条的损失可以直接比较。

**求导时的性质（来自卡 3 的加法规则和常数倍规则）：**

```
平均值的斜率 = 每一项斜率的平均值
```

因为平均值就是「加起来再乘以常数 1/n」，加法可以逐项求导，常数倍可以提出来。对偏导数同样成立。

**工具 `np.mean`：** 主角是一个 numpy 数组，返回所有元素的平均值。

```python
np.mean(np.array([1.0, 2.0, 6.0]))    # → 3.0
```

配合广播（[D6](derived.md#d-np-broadcast)）：对整个数组做逐元素运算，再 `np.mean`，就能不写循环算出「每条记录的某个量的平均值」。

## 卡 15：梯度下降的一步

**主角：** 当前位置 `params`（装着所有旋钮的数组）、损失在这个位置的梯度 `grad`、一个正数 `lr`。

前面已经知道：梯度指向上坡最陡的方向，所以下山要朝梯度的**反方向**走（[D19](derived.md#d-downhill)）。梯度下降就是把这句话写成一条更新规则：

```
新位置 = 旧位置 - lr × 梯度        # 每个旋钮各自减去「lr × 自己的偏导数」
```

**为什么要乘梯度，而不是每次走固定的距离：** 梯度的长度就是坡的陡峭程度。坡陡时离谷底通常还远，步子自动变大；接近谷底时坡变平，梯度趋近 0，步子自动变小，不会在谷底附近乱晃。

**为什么还要乘一个 `lr`：** 梯度是斜率，不是距离，它的数值可以很大（第 3 关起点处是 `[-230, -70]`）。直接减掉梯度，一步就不知道跨到哪里去了。所以乘上一个小的正数把步子缩小，这个数叫**学习率**（learning rate，代码里常写 `lr`，数学书里常写希腊字母 `η`，读作 eta）。

**例：** `f(x) = x²`，站在 `x = 3`，`lr = 0.1`。这里的斜率是 `2 × 3 = 6`，所以新位置 `= 3 - 0.1 × 6 = 2.4`，离谷底 `x = 0` 近了一些。

---

## 卡 16：学习率的大小

**主角：** 学习率 `lr`，和下山的整条路径。

| `lr` | 路径 |
|---|---|
| 太小 | 每一步都在下降，但走得极慢，要很多步才到谷底 |
| 合适 | 稳定地靠近谷底 |
| 太大 | 一步跨过谷底，落到对面的坡上；如果落点比出发点还高，就会越走越远 |

**两个术语：** 路径越来越靠近谷底，叫**收敛**（converge）；越走越远，叫**发散**（diverge）。

**怎么选：** 合适的范围取决于山谷本身的形状（越陡峭的山谷，能用的 `lr` 越小），事先通常不知道，实际做法是试：先取一个值跑一下，看损失是在下降还是在变大，再调整。

## 卡 17：训练循环与模型

**主角：** 一个从起点出发、重复执行很多次的循环。

「训练」就是把同样的两件事重复很多遍：

```
重复 n 次：
    1. 算出损失在当前位置的梯度
    2. 按卡 15 的规则走一步
```

每重复一遍叫一次**迭代**（iteration），也常叫一步（step）。

**损失记录：** 每走一步，把当时的损失存下来。这串数字叫**损失曲线**，是判断训练是否正常的主要依据：一路下降并逐渐变平，说明在收敛；变大或来回跳，说明学习率有问题。

**模型：** 训练结束时停在的那个位置（旋钮的最终取值）叫**训练好的参数**。预测公式 + 训练好的参数 = 一个**模型**。拿它去算从没见过的输入，叫**预测**（predict）。

**工具：numpy 数组的两种减法**（主角是数组 `a`）

```python
a = a - b      # 造出一个新数组，再让名字 a 指向它；原来那个数组不变
a -= b         # 直接修改 a 指向的那个数组本身；所有指向它的名字看到的都变了
```

**工具：往列表末尾加东西**（主角是列表 `record`）

```python
record = []
record.append(3.5)      # record 变成 [3.5]
```

### 补充：给 numpy 数组添加元素

**主角：** 一个 numpy 数组 `a`。

numpy 数组创建出来**长度就固定了**，不能像列表那样原地变长。`np.append` 实际上是造一个更长的**新数组**，把旧的内容复制过去，再把新元素放在末尾：

```python
a = np.array([1.0, 2.0])
a = np.append(a, 3.0)         # 返回新数组 [1. 2. 3.]；必须用 a = 接住，否则 a 不变
a = np.append(a, [4.0, 5.0])  # 一次加多个也行 → [1. 2. 3. 4. 5.]
```

**代价：** 每次 `np.append` 都要把整个数组复制一遍。在循环里每轮加一个，数组越长越慢。

**业界常用的两种写法：**

```python
# 写法 1：先用列表攒，最后一次性转成数组
record = []
record.append(1.0)            # 主角是列表 record，原地变长，很快
arr = np.array(record)        # 结束时转换一次

# 写法 2：事先知道一共几个，先开好全 0 的数组，再按下标填
arr = np.zeros(5)             # 形状 (5,) 的全 0 数组
arr[0] = 1.0                  # 主角是数组 arr，把第 0 个位置改成 1.0
```
