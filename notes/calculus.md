# 📒 微积分（为线性回归准备）知识笔记

> 2026-11-09 开始学习。路线：导数 → 链式法则 → 偏导 / 梯度 → 梯度下降。
> 配套练习见 [ai/math/](../ai/math/)

**为什么要学：** 线性回归（以及所有神经网络）的训练，本质上就是「在一个损失函数的山谷里找谷底」。导数告诉我们脚下的坡往哪边倾斜、有多陡，然后我们就知道该往哪走。

---

## 卡 1：导数 = 斜率

**主角：** 一个函数 `f`，和一个位置 `x`。

把 `f` 的图像想成一条山路，横轴是位置 `x`，纵轴是海拔 `f(x)`。
**`f` 在 `x` 处的导数**，就是站在 `x` 这一点时，脚下这条山路的**斜率**：往右走一小步，海拔变化多少。

| 导数的值 | 脚下的山路 |
|---|---|
| > 0 | 往右是上坡 |
| < 0 | 往右是下坡 |
| = 0 | 平的（可能是山顶，也可能是谷底） |
| 绝对值越大 | 坡越陡 |

**记号：** `f'(x)` 读作「f 撇 x」，表示 `f` 在 `x` 处的导数。另一种写法是 `df/dx`，`d` 表示「一点点变化」：`f` 的一点点变化 ÷ `x` 的一点点变化。

---

## 卡 2：数值导数（用代码近似求斜率）

**主角：** 函数 `f`、位置 `x`、一个很小的步长 `h`。

两点确定一条直线，直线的斜率 = 纵向变化 ÷ 横向变化。
在 `x` 和 `x + h` 两个很近的点上量海拔，就得到 `x` 附近的近似斜率：

```
            f(x + h) - f(x)
f'(x)  ≈  ─────────────────
                  h
```

- 分子 `f(x + h) - f(x)`：往右走 `h` 之后，海拔变了多少
- 分母 `h`：横着走了多远
- `h` 越小，这两个点越近，结果越接近真正的导数

**`h` 为什么不取 0：** 分母变成 0，没法除。
**`h` 为什么不取得特别小（比如 `1e-15`）：** 计算机里的小数有精度限制，`f(x + h)` 和 `f(x)` 几乎一样时，相减会丢掉大部分有效数字，结果反而不准。`1e-5` 左右是常用的折中。

## 卡 3：幂函数求导规则（手算导数）

**主角：** 形如 `xⁿ` 的函数（`x` 的 n 次方）。

```
(xⁿ)' = n · xⁿ⁻¹
```

即：指数 `n` 拿下来当系数，指数本身减 1。

| 函数 | 导数 |
|---|---|
| `x⁴` | `4x³` |
| `x³` | `3x²` |
| `x` | `1`（`x¹` → `1 · x⁰`） |
| 常数 `c` | `0`（平地没有坡） |

两条配套规则：
- **常数倍**：`(c · f)' = c · f'`，比如 `(5x³)' = 15x²`
- **加法**：`(f + g)' = f' + g'`，一项一项分别求导再加起来

**用途：** 手算的结果是精确值，可以用来检查卡 2 的数值导数算得对不对。

## 卡 4：`np.linspace`（等间距取点）

**主角：** 一个区间 `[start, stop]`，和要取的点数 `num`。

```python
np.linspace(start, stop, num)
```

在 `start` 到 `stop` 之间**等间距**取 `num` 个点，返回 numpy 数组，**两端都包含**。

```python
np.linspace(0, 1, 5)    # → array([0.  , 0.25, 0.5 , 0.75, 1.  ])
np.linspace(2, 3, 3)    # → array([2. , 2.5, 3. ])
```

**和 `range` / `np.arange` 的区别：**

| | 你指定的是 | 包含终点吗 |
|---|---|---|
| `range(a, b, step)` / `np.arange` | 步长 | ❌ 不包含 |
| `np.linspace(a, b, num)` | 点数 | ✅ 包含 |

**点数和间距的关系：** `num` 个点之间有 `num - 1` 个间隔，所以间距 = `(stop - start) / (num - 1)`。

## 卡 5：`np.abs`（绝对值）

**主角：** 一个数，或一个 numpy 数组。

```python
np.abs(-3)                       # → 3
np.abs(np.array([-2, 0, 1.5]))   # → array([2. , 0. , 1.5])
```

对数组是**逐个元素**取绝对值，返回同样形状的数组。

**用途：** 「离 0 有多近」看的是绝对值：`-0.1` 比 `0.5` 更接近 0，因为 `|-0.1| = 0.1 < 0.5`。

## 卡 6：把函数当参数传

**主角：** 一个接收「函数」作为参数的函数。

在 Python 里，函数也是一个对象，可以像数字一样当参数传进别的函数：

```python
def twice(g, x):          # g 是一个函数，x 是一个数
    return g(g(x))        # 对 x 连续用两次 g

def add3(x):
    return x + 3

twice(add3, 10)           # → 16，add3 后面没有括号：传的是函数本身，不是调用结果
```

**`lambda`：** 写一个临时的、只有一行的函数，不用起名字：

```python
twice(lambda x: x * 10, 2)    # → 200
# lambda x: x * 10  等价于  def 某函数(x): return x * 10
```

**和 numpy 配合：** 如果函数内部只用了 `+ - * / **` 这类运算，那么传入 numpy 数组时，这些运算会**逐个元素**进行（广播，见 [D6](derived.md#d-np-broadcast)），整个函数自动就能处理数组。
