# 📒 微积分（为线性回归准备）知识笔记

> 2026-11-09 开始学习。路线：导数 → 链式法则 → 偏导 / 梯度 → 梯度下降。
> 配套练习见 [ai/math/](../ai/math/)

**为什么要学：** 线性回归（以及所有神经网络）的训练，本质上就是「在一个损失函数的山谷里找谷底」。导数告诉我们脚下的坡往哪边倾斜、有多陡，然后我们就知道该往哪走。

---

## 卡 1：导数 = 斜率

**主角：** 一个函数 `f`，和一个位置 `x`。

把 `f` 的图像想成一条山路，横轴是位置 `x`，纵轴是海拔 `f(x)`。
**`f` 在 `x` 处的导数**，就是站在 `x` 这一点时，脚下这条山路的**斜率**：往右走一小步，海拔变化多少。

| 导数的值 | 脚下的山路 |
|---|---|
| > 0 | 往右是上坡 |
| < 0 | 往右是下坡 |
| = 0 | 平的（可能是山顶，也可能是谷底） |
| 绝对值越大 | 坡越陡 |

**记号：** `f'(x)` 读作「f 撇 x」，表示 `f` 在 `x` 处的导数。另一种写法是 `df/dx`，`d` 表示「一点点变化」：`f` 的一点点变化 ÷ `x` 的一点点变化。

---

## 卡 2：数值导数（用代码近似求斜率）

**主角：** 函数 `f`、位置 `x`、一个很小的步长 `h`。

两点确定一条直线，直线的斜率 = 纵向变化 ÷ 横向变化。
在 `x` 和 `x + h` 两个很近的点上量海拔，就得到 `x` 附近的近似斜率：

```
            f(x + h) - f(x)
f'(x)  ≈  ─────────────────
                  h
```

- 分子 `f(x + h) - f(x)`：往右走 `h` 之后，海拔变了多少
- 分母 `h`：横着走了多远
- `h` 越小，这两个点越近，结果越接近真正的导数

**`h` 为什么不取 0：** 分母变成 0，没法除。
**`h` 为什么不取得特别小（比如 `1e-15`）：** 计算机里的小数有精度限制，`f(x + h)` 和 `f(x)` 几乎一样时，相减会丢掉大部分有效数字，结果反而不准。`1e-5` 左右是常用的折中。

## 卡 3：幂函数求导规则（手算导数）

**主角：** 形如 `xⁿ` 的函数（`x` 的 n 次方）。

```
(xⁿ)' = n · xⁿ⁻¹
```

即：指数 `n` 拿下来当系数，指数本身减 1。

| 函数 | 导数 |
|---|---|
| `x⁴` | `4x³` |
| `x³` | `3x²` |
| `x` | `1`（`x¹` → `1 · x⁰`） |
| 常数 `c` | `0`（平地没有坡） |

两条配套规则：
- **常数倍**：`(c · f)' = c · f'`，比如 `(5x³)' = 15x²`
- **加法**：`(f + g)' = f' + g'`，一项一项分别求导再加起来

**用途：** 手算的结果是精确值，可以用来检查卡 2 的数值导数算得对不对。

## 卡 4：`np.linspace`（等间距取点）

**主角：** 一个区间 `[start, stop]`，和要取的点数 `num`。

```python
np.linspace(start, stop, num)
```

在 `start` 到 `stop` 之间**等间距**取 `num` 个点，返回 numpy 数组，**两端都包含**。

```python
np.linspace(0, 1, 5)    # → array([0.  , 0.25, 0.5 , 0.75, 1.  ])
np.linspace(2, 3, 3)    # → array([2. , 2.5, 3. ])
```

**和 `range` / `np.arange` 的区别：**

| | 你指定的是 | 包含终点吗 |
|---|---|---|
| `range(a, b, step)` / `np.arange` | 步长 | ❌ 不包含 |
| `np.linspace(a, b, num)` | 点数 | ✅ 包含 |

**点数和间距的关系：** `num` 个点之间有 `num - 1` 个间隔，所以间距 = `(stop - start) / (num - 1)`。

## 卡 5：`np.abs`（绝对值）

**主角：** 一个数，或一个 numpy 数组。

```python
np.abs(-3)                       # → 3
np.abs(np.array([-2, 0, 1.5]))   # → array([2. , 0. , 1.5])
```

对数组是**逐个元素**取绝对值，返回同样形状的数组。

**用途：** 「离 0 有多近」看的是绝对值：`-0.1` 比 `0.5` 更接近 0，因为 `|-0.1| = 0.1 < 0.5`。

## 卡 6：把函数当参数传

**主角：** 一个接收「函数」作为参数的函数。

在 Python 里，函数也是一个对象，可以像数字一样当参数传进别的函数：

```python
def twice(g, x):          # g 是一个函数，x 是一个数
    return g(g(x))        # 对 x 连续用两次 g

def add3(x):
    return x + 3

twice(add3, 10)           # → 16，add3 后面没有括号：传的是函数本身，不是调用结果
```

**`lambda`：** 写一个临时的、只有一行的函数，不用起名字：

```python
twice(lambda x: x * 10, 2)    # → 200
# lambda x: x * 10  等价于  def 某函数(x): return x * 10
```

**和 numpy 配合：** 如果函数内部只用了 `+ - * / **` 这类运算，那么传入 numpy 数组时，这些运算会**逐个元素**进行（广播，见 [D6](derived.md#d-np-broadcast)），整个函数自动就能处理数组。

## 卡 7：`np.argmin` / `np.argmax`（最小 / 最大值的下标）

**主角：** 一个 numpy 数组 `a`。

```python
a = np.array([5, 2, 9, 1, 7])

np.min(a)       # → 1   最小的值
np.argmin(a)    # → 3   最小值在 a 里的下标（a[3] 是 1）
```

`arg` 是 argument 的缩写：「让结果最小的那个输入」。`np.argmax` 同理，找最大值的下标。

**常见用法：在一个数组里找下标，去另一个等长的数组里取值**

```python
names = np.array(["野蛮人", "弓箭手", "巨人", "哥布林", "法师"])
costs = np.array([5, 2, 9, 1, 7])

names[np.argmin(costs)]    # → "哥布林"：在 costs 里找最小的下标，去 names 里取名字
```

**易错：** `argmin` 的结果是下标（第几个），不是值。要值就得再取一次：`a[np.argmin(a)]`。

## 补充：中心差分（卡 2 的标准写法）

**主角：** 函数 `f`、位置 `x`、步长 `h`。

卡 2 的公式只往右走一步，叫**前向差分**。标准写法是左右各走 `h`，叫**中心差分**：

```
            f(x + h) - f(x - h)
f'(x)  ≈  ─────────────────────
                   2h
```

- 分子：从 `x - h` 到 `x + h` 海拔变了多少
- 分母 `2h`：这两个点之间的横向距离

| | 误差 | `x²` 在 3 处、`h = 1e-5` 的实测误差 |
|---|---|---|
| 前向差分 | 和 `h` 成正比 | 约 `1e-5` |
| 中心差分 | 和 `h²` 成正比 | 约 `4e-11` |

**用途：** 深度学习里检查自己写的反向传播对不对（gradient check），用的就是中心差分。

## 卡 8：复合函数（一个函数套着另一个函数）

**主角：** 两个函数，里层 `g` 和外层 `f`。

先把输入 `x` 交给里层 `g`，`g` 的输出再交给外层 `f`，这样串起来的整体叫**复合函数**，写作 `f(g(x))`。

例：`y = (5x - 1)³` 是两步：

| 步骤 | 谁 | 输入 | 输出 |
|---|---|---|---|
| 第 1 步（里层） | `g(x) = 5x - 1` | `x` | 记作 `u` |
| 第 2 步（外层） | `f(u) = u³` | `u` | `y` |

**为什么要引入新名字 `u`：** `(5x - 1)³` 整体不是卡 3 里的 `xⁿ`，没法直接用幂函数规则。把里层的输出起名叫 `u` 之后，外层就变成了 `u³`，这是会求导的形状。`u` 只是「里层输出」的名字，没有别的含义。

**怎么认里外层：** 算数值时**先算的是里层**，后算的是外层。

---

## 卡 9：链式法则（复合函数的斜率 = 每一层斜率相乘）

**主角：** 复合函数 `y = f(g(x))`，其中 `u = g(x)` 是里层的输出。

```
dy     dy     du
──  =  ──  ·  ──
dx     du     dx
```

- `dy/dx`：整体的斜率（`x` 变一点点，`y` 变多少）← 我们想要的
- `dy/du`：外层 `f` 的斜率（`u` 变一点点，`y` 变多少）
- `du/dx`：里层 `g` 的斜率（`x` 变一点点，`u` 变多少）

**为什么是相乘（齿轮直觉）：** 第一个齿轮转 1 圈，第二个跟着转 5 圈；第二个转 1 圈，第三个跟着转 3 圈。那第一个转 1 圈，第三个转 `5 × 3 = 15` 圈。斜率就是这种「放大倍数」，一级接一级，倍数相乘。

**为什么是相乘（式子）：** 让 `x` 变一点点 `Δx`（`Δ` 读「德尔塔」，表示「变化量」），`u` 跟着变 `Δu`，`y` 跟着变 `Δy`。

```
Δy     Δy     Δu
──  =  ──  ·  ──        # 右边的 Δu 上下约掉，就是左边
Δx     Δu     Δx
```

**例：** `y = (5x - 1)³`，求 `x = 1` 处的斜率。

1. 拆层：`u = 5x - 1`，`y = u³`
2. 里层的斜率：`du/dx = 5`
3. 外层的斜率：`dy/du = 3u²`
4. 相乘：`dy/dx = 3u² · 5`
5. 代数：`x = 1` 时 `u = 5·1 - 1 = 4`，所以 `dy/dx = 3 · 4² · 5 = 240`

**⚠️ 最容易错的地方：外层的斜率在 `u` 处取值，不是在 `x` 处。** 外层 `f` 吃进去的是 `u`，它根本不认识 `x`。上面第 5 步里，`3u²` 代的是 `u = 4`，不是 `x = 1`。

## 卡 10：多层链 + 两趟走法（前向 / 反向）

**主角：** 三层或更多层串起来的函数，例如 `x → u → v → y`。

层数再多，规则不变，每一层的斜率全部乘起来：

```
dy     dy     dv     du
──  =  ──  ·  ──  ·  ──
dx     dv     du     dx
```

每一层的斜率都在**它自己的输入**处取值：`dy/dv` 在 `v` 处，`dv/du` 在 `u` 处，`du/dx` 在 `x` 处。

所以实际计算分两趟：

| 趟 | 方向 | 做什么 | 名字 |
|---|---|---|---|
| 第 1 趟 | 从里到外 | 依次算出 `u`、`v`、`y` 的**值**，并记下来 | 前向传播（forward pass） |
| 第 2 趟 | 从外到里 | 用记下来的值算每一层的斜率，一路乘回去 | 反向传播（backward pass / backpropagation） |

**这就是神经网络训练用的反向传播。** 神经网络是很多层套起来的复合函数，反向传播就是对它用链式法则。PyTorch 的 `loss.backward()` 做的就是第 2 趟。
