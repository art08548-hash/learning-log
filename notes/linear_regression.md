## 卡 1：多特征模型

**主角：** 一本账本，`n` 条记录，每条记录有 `d` 个特征。

上一关每条记录只有 1 个特征（城墙等级），模型是 `w × x + b`。现实里影响结果的因素不止一个，每个特征各配一个权重：

```
预测 = x₀ · w₀ + x₁ · w₁ + … + x_{d-1} · w_{d-1} + b
```

- `w₀ … w_{d-1}`：**权重**（weight），每个特征一个，表示「这个特征每多 1，预测多多少」
- `b`：**偏置**（bias），所有特征都为 0 时的预测，就是上一关的「开工费」

**整本账本的写法（业界约定，直接记）：**

| 名字 | 形状 | 含义 |
|---|---|---|
| `X` | `(n, d)` | 特征矩阵：**每一行是一条记录，每一列是一个特征** |
| `y` | `(n,)` | 每条记录的真实值 |
| `w` | `(d,)` | 权重，每个特征一个 |
| `b` | 一个数 | 偏置 |

**为什么 `X` 大写、`y` 小写：** 数学里约定大写字母表示矩阵，小写字母表示向量或数。代码里沿用这个习惯，一眼就能看出谁是二维的。

## 卡 2：随机数生成器与噪声

**主角：** 一个随机数生成器 `rng`。

```python
rng = np.random.default_rng(7)          # 造一个生成器；7 是种子（seed）
rng.integers(1, 16, size=200)           # 200 个随机整数，范围 1～15（右端 16 取不到）
rng.normal(0, 3, size=200)              # 200 个正态分布的随机小数，平均值 0，标准差 3
```

**种子是干什么的：** 生成器其实是一台按固定规则吐数字的机器，种子决定从哪开始吐。种子相同，每次运行得到的「随机数」完全一样。这样你、我、自测拿到的是同一本账本，结果可以复现。

**噪声：** 真实数据不会精确落在任何公式上，总有测不准、说不清的因素。`rng.normal(0, 3, ...)` 模拟的就是这部分：大多数落在 `-3 ~ 3` 之间，偶尔大一点，平均为 0。

**两个拼数组的工具：**

```python
np.column_stack([a, b, c])    # 主角是三个形状 (n,) 的数组：把它们当成三列，拼成形状 (n, 3) 的矩阵
arr.astype(float)             # 主角是数组 arr：返回一个元素都转成小数的新数组
```

## 卡 3：标准化（z-score）

**主角：** 特征矩阵 `X` 的**某一列**（一个特征）。

不同特征的数值范围可能差很多：城墙等级是 1～15，段数是 50～300。**标准化**就是把每一列换算到同一个尺度上：

```
标准化后的值 = (原始值 - 这一列的平均值) / 这一列的标准差
```

换算之后，每一列的平均值都是 0，标准差都是 1。这个换算后的值叫 **z 分数**（z-score），意思是「比平均值高出几个标准差」。

**标准差回顾：** 主角是一组数，衡量它们离平均值有多分散：

```
标准差 = √( (每个数 - 平均值)² 的平均值 )
```

```python
np.std(a)              # 主角是数组 a：所有元素的标准差
np.std(X, axis=0)      # 主角是矩阵 X：沿第 0 轴（行的方向）压缩，每一列得到一个标准差，形状 (d,)
```

`axis=0` 的规则就是 numpy 第 3 章学过的：`axis` 填哪个，形状里那一维就消失。

**为什么要做这一步：** 这一关的任务 4 你会亲眼看到。

## 卡 4：`inf`、`nan` 与 overflow 警告

**主角：** 一个越算越大的数。

小数（`float`）能表示的最大值约是 `1.8 × 10³⁰⁸`。超过它就变成 `inf`（infinity，无穷大），numpy 会打印一条警告：

```
RuntimeWarning: overflow encountered in ...
```

`inf` 再参与运算，比如 `inf - inf`、`0 × inf`，结果无法确定，就变成 `nan`（Not a Number，不是一个数）。

| 值 | 含义 | 判断方法 |
|---|---|---|
| `inf` | 太大，存不下 | `np.isinf(x)` |
| `nan` | 算不出来 | `np.isnan(x)` |
| 正常的数 | | `np.isfinite(x)` 为 `True` |

**注意：** `nan` 和任何数比较大小都是 `False`，连 `nan == nan` 也是 `False`。

**训练中看到它们，几乎总是说明发散了。** 大模型训练日志里看到 `loss: nan`，第一反应就是去查学习率和梯度。
