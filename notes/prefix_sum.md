## 卡 1：核心定义，以及为什么要"多一位"

`prefix[i]` = **前 i 个元素**的和，长度 **n+1**，`prefix[0] = 0`：

```python
nums   =    [3, -2,  5,  1]
prefix = [0, 3,  1,  6,  7]   # prefix[i] = nums[0] + ... + nums[i-1]
```

**区间和公式**（闭区间 `[l, r]`）：

```python
sum(nums[l:r+1]) == prefix[r+1] - prefix[l]
```

- 多出来的 `prefix[0] = 0`：让 `l = 0` 时不用特判
- 复杂度：预处理 O(n)，每次查询 O(1)

构建：

```python
# 手写
prefix = [0]
for x in nums:
    prefix.append(prefix[-1] + x)

# 标准库
from itertools import accumulate
prefix = list(accumulate(nums, initial=0))
```

### 补充：左闭右开约定

Python 的切片 `a[l:r]` 和 `range(l, r)` 都是 **`[l, r)`**：包含 l，不包含 r。

```python
a[i:j]                      # 长度正好是 j - i
a[i:j] + a[j:k] == a[i:k]   # 首尾相接，不重叠也不漏
a[i:i]                      # 空区间
range(5)                    # 0, 1, 2, 3, 4
```

用左闭右开写前缀和更干净：

```python
sum(nums[l:r])   == prefix[r]   - prefix[l]   # [l, r)：没有 +1
sum(nums[l:r+1]) == prefix[r+1] - prefix[l]   # [l, r]：多一个 +1
```

卡 1 里的 `+1` 不是前缀和本身需要的，而是把"两端都包含"换算成 Python 的左闭右开。

## 卡 2：前缀和 + 哈希表（边遍历边查）

区间和 = k ⇔ 两个前缀和之差 = k。变化在于**哈希表存什么**：

| 哈希表存的值 | 能解决的问题 | 初始值 |
|---|---|---|
| 某个前缀和**出现了几次** | 和为 k 的子数组**有几个** | `{0: 1}` |
| 某个前缀和**第一次出现的下标** | 和为 k 的**最长**子数组 | `{0: -1}` |
| 前缀和**除以 k 的余数** | 和是 k 的**倍数**的子数组 | 看题目要求 |

- **关于余数**：`(p_j - p_i) % k == 0` ⇔ `p_j % k == p_i % k`。Python 里 `-7 % 5 == 3`，结果自动非负；C++ 和 Java 会得到负数，需要手动修正
- **关于"求最长"**：同一个前缀和只记**第一次**出现的位置，之后不要覆盖。离得越远，子数组越长
- **转化思想**：有时先把元素变换一下，让问题变成"和等于某个值"
- **先查再存**：先用 `prefix - k` 去查，再把当前前缀和存进去

模板（计数版）：

```python
counts = {0: 1}
prefix = result = 0
for x in nums:
    prefix += x
    result += counts.get(prefix - k, 0)        # 先查
    counts[prefix] = counts.get(prefix, 0) + 1 # 再存
```

## 卡 3："前缀"不只能求和

只要一种运算能"抵消"，就能做前缀：

| 前缀类型 | 区间结果 | 原理 |
|---|---|---|
| 前缀和 | `p[r+1] - p[l]` | 减法抵消加法 |
| 前缀异或 | `px[r+1] ^ px[l]` | `a ^ a = 0`，异或两次就抵消了 |
| 前缀积 | `p[r+1] / p[l]` | ⚠️ 数组里有 0 就不能用除法 |

**前后缀分解**：有些问题要同时知道"左边所有"和"右边所有"的信息，就分别算一个前缀数组和一个后缀数组，再合并。

## 卡 4：二维前缀和

`P[i][j]` = 矩阵左上角 i 行 × j 列这块矩形的和，大小 `(m+1) × (n+1)`。

**构建：**

```python
P[i+1][j+1] = P[i][j+1] + P[i+1][j] - P[i][j] + M[i][j]
#             上面一块     左边一块    重叠部分减掉一次   自己
```

**查询**子矩形 `(r1, c1)` 到 `(r2, c2)`（两端都包含）：

```python
P[r2+1][c2+1] - P[r1][c2+1] - P[r2+1][c1] + P[r1][c1]
#   整块         减掉上方       减掉左方      左上角被减了两次，加回来一次
```

这就是**容斥原理**，拿不准时在纸上画四个矩形。

⚠️ 创建二维数组：

```python
grid = [[0] * n] * m                # ❌ 每一行都是同一个列表
grid = [[0] * n for _ in range(m)]  # ✅ 每行独立
```

## 卡 5：差分数组，前缀和的"逆运算"

`diff[i] = a[i] - a[i-1]`，对 diff 做一遍前缀和就能还原出 a。

**给区间 `[l, r]` 全部加上 v，只改两个位置：**

```python
diff[l] += v
diff[r + 1] -= v      # diff 开 n+1 长，r+1 才不会越界
```

所有修改做完，再做一次前缀和得到最终数组。

- 适用场景：很多次区间修改，最后一次性查看结果
- 复杂度：每次修改 O(1)，还原一次 O(n)

## 卡 6：什么时候不用前缀和，以及易错清单

**不适合的情况：**
- 数组一边**频繁修改**一边查询：每改一次就要 O(n) 重建 → 用树状数组 / 线段树
- 元素**全部非负**，找最短或最长子数组：滑动窗口通常更好，空间 O(1)
- 有**负数**时，窗口和不再随右扩单调变化 → 滑动窗口失效，换前缀和
- 整数溢出：Python 不用担心，换成其他语言要用 long

**易错清单：**
1. 下标差一位：prefix 长度是 n+1，`[l, r]` 对应 `prefix[r+1] - prefix[l]`
2. 哈希表初始值：计数用 `{0: 1}`，求最长用 `{0: -1}`
3. 先查再存
4. 求最长时只存第一次出现的下标
5. 二维查询时，左上角要加回来
6. 构建前缀数组时别漏了第 0 个元素（直接 `for x in nums` 遍历最安全）
